# Tutorial Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. The owner prefers inline execution, committing and pushing after every task.

**Goal:** A first-time player is guided by their orb (a labelled "Guide") from founding a company to the first customers, and can skip or turn the guide off at any time.

**Architecture:**
- Client-only.
- A guide engine runs an ordered list of steps; each step's "done" is a predicate over the world view and the current screen, so the guide follows what the player really does.
- The Guide bubble is a component distinct from chat bubbles.
- Progress lives in local storage per player name.

**Tech Stack:** React, zustand, motion (as the client).

**Spec:** `docs/superpowers/specs/2026-11-04-remaining-features-design.md` §7 (decision C46).

## Global Constraints

- **R1:**
  - Guide lines are game-written.
  - The bubble is labelled **"Guide"**, with its own style: a dashed border and a guide icon, never the chat bubble style.
  - The AI's own words appear only in chats and posts.
- **Steps, in order, with their exact lines and when each is done:**
  1. `found`: "Welcome! Let's build an AI company. Name it and pick its colors." Done: you have a company.
  2. `reading`: "Your AI learns from what it reads. This is its reading list: more Conversations helps it chat." Done: the Data step was opened.
  3. `train`: "Press Start training, then watch it learn: the line falls as its guesses get better." Done: a run exists.
  4. `chat`: "It's ready! Say hello in the Playground. Every word it says is its own." Done: you sent a chat to your AI.
  5. `scores`: "Benchmarks show what it's good at. Every score is measured from its real answers." Done: Benchmarks opened after a scored version exists.
  6. `launch`: "Launch it so customers can use it: pick a name and a plan." Done: a product exists.
  7. `customers`: "Customers are arriving. Their posts quote what your AI really told them." Done: you have more than 0 customers.
  8. `done`: "You're running an AI company. The rest is up to you. Good luck!" Done: closed.
- **Controls:**
  - "Skip this step" and "Skip the tutorial" on every bubble.
  - Home → Settings → **"Show the guide"** (on by default for a new player name; off hides it everywhere; on again restarts from the first unfinished step).
  - "Start the tutorial again" on Home.
- **Storage:** `localStorage["airace.guide.<playerName>"] = {step, off}`, wrapped in try/catch. Without storage it shows once per session.
- **Highlight:** each step rings its control (`data-guide="<step>"` attributes on the target).

## Review Focus

1. **A player who already did a step's action before the guide reached it** (for example, opened Benchmarks early) sees the step marked done at once; the guide never asks for something already done. Owner: Task 1.
2. **A returning player** with a world already past launch: the guide skips every done step and shows only what's left, or nothing. Owner: Task 1.
3. **Storage blocked** (a private window): no crash; the guide shows once this session. Owner: Task 1.
4. **The target control not on screen** (another tab): the bubble says where to go ("Open the AI Lab") instead of ringing nothing. Owner: Task 2.
5. **The guide never covers a window or dialog's buttons:** it hides while a window is open. Owner: Task 2.
