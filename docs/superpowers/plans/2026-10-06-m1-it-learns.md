# Milestone 1 "It Learns" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the real miniature-language-model core of AI Race. It covers the tokenizer, model, function-preserving growth, training, inference, the content pipeline, benchmarks and the personality fingerprint, and it must pass the feasibility gate in spec §4.12.

**Architecture:** A single Python uv project at `ml/` with two packages.
- `airace_ml` is runtime code: model, training, inference, evals, personality, experiments and the CLI. It later becomes the ML worker.
- `airace_content` is build-time code: it fetches open datasets, adds procedural skill data, injects tagged noise, and writes token shards.
- Procedural skill generators (`airace_ml.skills`) are shared by training-data assembly and benchmarks. A hash partition keeps the two disjoint.
- No game server or UI in this milestone.

**Tech Stack:**
- Python 3.13 (uv-managed)
- PyTorch 2.14.1 (CUDA 13 wheels on Windows/Linux)
- Hugging Face `tokenizers`, `safetensors`, numpy
- `datasets` (content extra only)
- pytest, ruff

**Spec:** `docs/superpowers/specs/2026-10-06-ai-race-architecture-design.md` (sections §1, §4, §11–§13 apply here). Read it first.

## Global Constraints

**Toolchain**
- Python `>=3.13,<3.14` via uv. Pins: `torch==2.14.1`, `numpy>=2.5`, `tokenizers>=0.23`, `safetensors>=0.8`. Content extra: `datasets>=5.1`. Dev: `pytest>=9`, `ruff>=0.16`.

**Tokenizer**
- Vocabulary 4096. 16 special tokens with IDs 0–15 in this exact order:
  `<|pad|> <|bos|> <|end|> <|user|> <|ai|> <|sep|> <|sys|> <|r0|> … <|r8|>`
- Tokenizer version `tok-v1`, frozen once built. Corpus version `v1`. Benchmark suite `bench-v1`.

**Model**
- Head dim 32. `d_model` is a multiple of 32 in [64, 1024]. `n_layer` in [1, 24]. `ctx_len` is a multiple of 64 in [64, 1024]. Max parameters 85,000,000.
- Shape only grows within a lineage.

**Data**
- Dataset IDs are fixed: `web, books, educational, conversations, code, reasoning, facts, creative`. Custom datasets: `notebook, coaching`.

**Safety and determinism**
- R1: no scripted or templated model output anywhere.
- Model-written code runs only in MiniPy. `exec`, `eval` and `compile` are never applied to model output.
- All randomness flows from explicit seeds (`numpy.random.Generator`, `torch.Generator` / `torch.manual_seed`).

**Testing and I/O**
- Tests are offline and CPU-only by default, and the default suite finishes in under 3 minutes. Use `@pytest.mark.slow` and `@pytest.mark.gpu` for heavy tests.
- Generated data goes under `data_root()` (`AIRACE_DATA` env, default `<repo>/data`) and is never committed.
- All text file I/O is explicit `encoding="utf-8"`.

**Licensing**
- Dataset sources must be permissively licensed and recorded in `manifest.json` and `docs/data-sources.md`.

## Review Focus

1. **Literal special-token strings in text.** If a player types `<|end|>` or `<|ai|>`, or a dataset contains them, they are tokenized as plain text, never as control tokens. Owner: Task 2.
2. **Chat history longer than the attention span.** The reply still generates. The oldest turns are dropped, the prompt starts with `<|bos|>` and ends with `<|ai|>`, and there is no position overflow. Owner: Task 5.
3. **Unsampleable mixtures.** These fail with `MixtureError` naming the dataset, before any training step:
   - all-zero or negative weights
   - unknown dataset IDs
   - a positive weight on a dataset whose pool is empty after prep or purchase
   - a notebook of only blank entries

   Owners: Tasks 6, 8.
4. **Degenerate model outputs** (empty generations, only special tokens, endless repetition) in benchmarks, creativity scoring and fingerprints. Scores come out finite (0 where appropriate), never NaN or a ZeroDivisionError. Owners: Tasks 16, 17, 18.
5. **Non-ASCII text** (accents, emoji, CJK, and the Windows cp1252 console) through tokenizer round-trip, corpus build and CLI printing. Round-trip is lossless and nothing crashes. Owners: Tasks 2, 19.

### Task 3: Model shape, transformer, checkpoint

**Files:**
- Create: `ml/src/airace_ml/model/__init__.py`, `shape.py`, `transformer.py`, `checkpoint.py`
- Test: `ml/tests/test_model.py`

**Interfaces:**
- Consumes: `VOCAB_SIZE` (Task 2).
- Produces:
  - `HEAD_DIM = 32`, `MAX_PARAMS = 85_000_000`, `class ShapeError(ValueError)`
  - `@dataclass(frozen=True) class ModelShape(n_layer: int, d_model: int, ctx_len: int)` with:
    - properties `n_head = d_model // 32` and `ffn_hidden = 64 * ceil(8 * d_model / 3 / 64)`
    - `param_count(vocab_size: int = VOCAB_SIZE) -> int`
    - `validate(vocab_size: int = VOCAB_SIZE) -> None`
    - `to_dict() -> dict`, `from_dict(d: dict) -> ModelShape` (classmethod)
  - `class KVCache` with fields `k: list[Tensor]`, `v: list[Tensor]` (per layer `[B, H, T, 32]`) and `length: int`
  - `class Transformer(nn.Module)`:
    - `__init__(shape: ModelShape, vocab_size: int = VOCAB_SIZE)`
    - attributes `shape`, `tok_emb: nn.Embedding`, `blocks: nn.ModuleList`, `norm_f: RMSNorm`, `lm_head: nn.Linear` (weight tied to `tok_emb.weight`)
    - `forward(idx: LongTensor[B,T], *, positions: LongTensor[B,T] | None = None, key_padding_mask: BoolTensor[B, T_total] | None = None, kv_cache: KVCache | None = None) -> Tensor[B,T,V]`. `True` in the mask means a real token. When a cache is given, it is updated in place.
    - `new_kv_cache() -> KVCache`, `num_params() -> int` (unique parameters)
  - Block layout for every block `b`: `b.attn_norm, b.attn.wq, b.attn.wk, b.attn.wv, b.attn.wo, b.mlp_norm, b.mlp.w_gate, b.mlp.w_up, b.mlp.w_down`. All are bias-free `nn.Linear`. Growth (Task 4) depends on these names.
  - `class RMSNorm(nn.Module)`: parameter `weight`, plus a registered **buffer** `eps` (float32 scalar, default 1e-5) that is saved in the state dict.
  - `@dataclass class CheckpointMeta` with fields:
    - `tokenizer: str`, `shape: ModelShape`
    - `lineage_id: str`, `version_id: str`, `parent_version_id: str | None`
    - `tokens_trained_total: int`, `last_mixture: dict[str, float]`, `runs: list[dict]`
    - `format: int = 1`
    - methods `to_json() -> str` and `from_json(s) -> CheckpointMeta` (classmethod)
  - `save_checkpoint(model: Transformer, meta: CheckpointMeta, out_dir: Path) -> None` writes `model.safetensors` and `meta.json`.
  - `load_checkpoint(ckpt_dir: Path, device: torch.device | str = "cpu") -> tuple[Transformer, CheckpointMeta]`

### Task 4: Function-preserving growth

**Files:**

**Interfaces:**
- Consumes: `ModelShape`, `Transformer` block layout, `RMSNorm.eps` buffer (Task 3).
- Produces:
  - `class GrowthError(ValueError)`
  - `insertion_layout(n_old: int, n_new: int) -> list[int | None]`: the new model's block list, where an `int` is a copied old block index and `None` is a fresh block.
  - `grow(model: Transformer, target: ModelShape, *, seed: int) -> Transformer`: returns a new model on the same device.

```python
import pytest, torch
from airace_ml.model.growth import GrowthError, grow, insertion_layout
from airace_ml.model.shape import ModelShape
from airace_ml.model.transformer import Transformer

def _perturbed(shape):
    torch.manual_seed(0); m = Transformer(ModelShape(*shape), 512)
    with torch.no_grad():
        for p in m.parameters():
            p.add_(0.1 * torch.randn_like(p))   # make norm gains != 1 so the test is meaningful
    return m.eval()

@pytest.mark.parametrize("src,dst", [((2, 64, 64), (2, 128, 64)), ((2, 64, 64), (4, 64, 64)),
                                     ((2, 64, 64), (5, 96, 128)), ((1, 64, 64), (1, 64, 64))])
def test_growth_preserves_function(src, dst):
    m = _perturbed(src); x = torch.randint(0, 512, (2, 48))
    torch.testing.assert_close(grow(m, ModelShape(*dst), seed=1).eval()(x), m(x), atol=1e-4, rtol=0)

def test_growth_rejects_shrinking():
    m = _perturbed((2, 96, 64))
    for bad in [ModelShape(1, 96, 64), ModelShape(2, 64, 64)]:
        with pytest.raises(GrowthError):
            grow(m, bad, seed=0)

def test_insertion_layout():
    assert insertion_layout(4, 6) == [0, 1, None, 2, 3, None]
```

**Interfaces:**

- Produces in `textproc.py`:

    - `k = clip((known_ratio - 0.5) / 0.4)`, over words of length ≥ 2
    - `r = 1 - repeated_line_ratio`
    - `g = 1 - clip(20 * garble_ratio)`, where garble_ratio is the share of characters in `MOJIBAKE_CHARS` = set("ÃÂâ€™œ¢�¤¦§¨©ª«¬®¯°±²³´µ¶·¸¹º»¼½¾")

    - **Result:** `k * g * p * (0.5 + 0.5 a) * (0.5 + 0.5 r)`; 0 for empty text.
- Produces in `noise.py`:
  - `@dataclass class NoiseRates(typo=0.0, spam=0.0, boilerplate=0.0, garbled=0.0, duplicate=0.0, false_fact=0.0)`

    - `load(dir: Path, device=None) -> Judge` (classmethod)
    - `nll_per_token(token_lists: list[list[int]]) -> list[float]`: mean NLL over the given tokens, conditioned on a leading `bos`; `inf` for an empty list.

  - `calibrate(judge: Judge, data_root: Path) -> JudgeCalibration`: 10th/90th percentile NLL of the first 96 tokens of up to 500 held-out creative documents, plus the 90th percentile NLL of up to 500 held-out conversation AI-reply segments.
  - `build_judge(data_root: Path, *, device=None, on_event=None, token_budget: int | None = None) -> Path`: trains into `judge_dir(data_root)` and writes `calibration.json`.
  - `is_well_formed(reply: str, judge: Judge) -> bool`: ≥ 4 words, no word 3-gram occurring ≥ 3 times, and `nll_per_token(encode(reply)) <= conv_reply_p90`.
- Produces in `creativity.py`:
  - `STORY_PROMPTS: tuple[str, ...]`: exactly 24 chat prompts of the form "Write a short story about …".
  - `score_creativity(lm, tok, judge, novelty, *, seed: int = 0, max_new_tokens: int = 96) -> tuple[CategoryScore, list[ItemResult]]`:
    1. One sampled story per prompt (temperature 0.9, top_p 0.95, seed + i).
    2. `c = clip((p90 - nll) / (p90 - p10), 0, 1)` using the judge's creative calibration.
    3. `nov = novelty.novelty(ids)`.
    4. `story = c * (0.4 + 0.6 * nov)`.
    5. `d` = distinct-2 over all stories' word bigrams (0 if none).
    6. **Score:** `100 * mean(story) * (0.5 + 0.5 * d)`. `raw` = `mean(story)`. Empty stories score 0.

  - `garble_rate(texts: list[str], known_vocab: set[str]) -> float`: fraction of words not in `known_vocab`; 0 if there are no words.
  - `false_fact_rate(lm, tok, kb, plan: FalseFactPlan) -> float`: for each planned (subject, relation) pair, render `relation.train_templates[0]` up to `{o}` as the context; the fact counts as false-preferred when `score(" " + false) > score(" " + true)`. Returns the fraction that are false-preferred.
  - `@dataclass class GateOutcome(criteria: list[GateCriterion], transcripts: dict[str, list[tuple[str, str]]], raw: dict)`
  - `run_gate(data_root: Path, out_dir: Path, *, seeds: Sequence[int] = (1, 2, 3), device=None, include_cpu_speed: bool = False, quick: bool = False, on_progress: Callable[[str], None] = print) -> GateOutcome`. `quick=True` swaps in shape `(2, 64, 64)`, a budget of 1024 × 20 tokens, `batch_tokens=1024` and a single seed, for smoke tests. Experiments:

    | Criterion | Experiment |
    |---|---|
    | G1 speed | `BALANCED_MIX`, `STARTER_SHAPE`, `STARTER_BUDGET`, timed, on GPU (and CPU when `include_cpu_speed`) |
    | G2 legibility | balanced starter, seed 1; 20 open/help probe replies via `chat_reply`; `is_well_formed` each; keep the transcript |
    | G3 differentiation | 4 `mix_heavy` targets × seeds, at `EARLY_SHAPE` / `EARLY_BUDGET`; full bench with creativity |
    | G4 seed variation | balanced `EARLY_SHAPE` × seeds; fingerprints; pairwise distances using all the gate's fingerprints as the population, compared with distances between the G3 mixes (seed 1) |
    | G5 growth | starter model (seed 1); max abs logit difference after `grow` to `EARLY_SHAPE` on 4 held-out sequences; continue +`STARTER_BUDGET` grown vs. ungrown on `BALANCED_MIX`; compare the final mean held-out loss |
    | G6 forgetting | `mix_heavy("creative")` at `EARLY_SHAPE` (seed 1) = base; continue +`STARTER_BUDGET` with mixture `{"code": 1}` and replay 0 vs 0.3; bench language + creativity |
    | G7 prep | (a) `mix_heavy("web", 0.7)` with `PrepConfig("light")` vs `PrepConfig("thorough", dedup=True)`, measuring `garble_rate` of 60 `complete()` samples from web held-out prefixes; (b) `{"web": 0.5, "facts": 0.5}` with `fact_check` False vs True, measuring `false_fact_rate`. Each at `STARTER_SHAPE` with 2× `STARTER_BUDGET` |

    All runs go under `out_dir/runs/<name>`.
- Produces in `report.py`:
  - `write_gate_report(outcome: GateOutcome, path: Path) -> None`: Markdown with a summary table (id, title, PASS/FAIL, detail); per-criterion data tables; G2 and G3 transcripts (≤ 10 exchanges each); the 4 differentiation models' bench tables side by side; and each model's `describe` words.
